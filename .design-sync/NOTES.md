# design-sync notes — SmarterVote Design System

- **Source repo is Svelte, not React.** SmarterVote's production frontend (`web/`) is SvelteKit + Tailwind. There is no React design system in the repo to sync — `design-system/` was built from scratch specifically to feed this sync, replicating the Svelte app's visual identity (tokens, ~20 components) in React + Tailwind. It is not wired into the production app and is not kept automatically in sync with `web/` — if the Svelte app's brand/tokens change, `design-system/src/styles/tokens.css` and `design-system/tailwind.config.js` need to be updated by hand to match `web/src/app.css` / `web/tailwind.config.js`.
- **Fonts**: the real app loads Inter via a Google Fonts CDN `<link>` in `web/src/app.html` (weights 400/500/600/700), not self-hosted. Google's CSS declares `@font-face` at runtime, which the design-sync render environment can't rely on loading. Installed `@fontsource/inter` as a devDependency in `design-system/` and pointed `cfg.extraFonts` at its `latin-400/500/600/700.css` files (latin-subset only, matching the weights the real app loads) so Inter ships self-hosted in the bundle instead of falling back to a system font.
- **Excluded from scope** (documented, not silently dropped — see the repo's plan history): `USMap` (D3/topojson choropleth), `CandidateComparison` (large sticky comparison grid), `IssueTable`/`DonorTable`/`VotingRecordTable` (raw data tables — `CandidateCard`'s Donors/Voting tabs render a simplified summary+source-link version inline instead), `ElectionDirectory`/`BallotExplorer`/`ElectionLookup`/`InteractiveRaceCompare` (page-level sections composable from the shipped primitives/composites), `ReviewPanel`, `ArtifactsList`, `support/*`, all `admin/`+pipeline tooling.
- **`SiteHeader`'s live search autocomplete** (SvelteKit routing/`goto`/`page` store driven in the original) was simplified to a controlled input + an optional `searchResults` slot — the original's keyboard-nav dropdown logic is app-routing-specific and wasn't ported.
- **`Tooltip`'s open state can't render statically.** It's internal `useState` (click-to-open), not prop-controlled, so its preview cards only show the closed trigger — the popover panel content is real but never appears in a static screenshot. Same for `ValidationGradeBadge`'s popover (built on `Tooltip`).
- **Dark-mode preview wrappers need `className="dark"` on the wrapper element, not just a dark background color.** `design-system` uses Tailwind `darkMode: "class"` plus a `.dark { --sv-*: ... }` token override (`design-system/tailwind.config.js`, `design-system/src/styles/tokens.css`) — both `dark:` variant classes and the `text-content`/`bg-surface`-style CSS-custom-property tokens only flip when an ancestor literally has the `dark` class. A `style={{ background: '#0b1220' }}` div alone does nothing; text renders in light-mode colors on a dark background (illegible). Watch for this in any future dark-mode preview cell.
- **`FeaturedElections`, `HowItWorks`, and `SiteHeader` need `cardMode: "column"`** (set in `cfg.overrides`, alongside `CandidateCard`'s existing override) — their layout primitives (a no-wrap `justify-between` header, a `sm:grid-cols-3` step grid, and a `flex-wrap` row with a fixed-width search box) don't reflow at the design-sync capture harness's effective grid-cell width and get hard-clipped otherwise. `TrustPrinciples`/`ImpactMetrics`, which stack to a single column below `lg`, don't need the override.

## Re-sync risks
- If `web/src/app.css` / `web/tailwind.config.js` tokens change, `design-system/` will silently drift out of sync — there's no automated check tying the two together.
- The `@fontsource/inter` version pin could fall behind the Google Fonts CDN version the live site actually serves; cosmetically minor (same typeface) but worth knowing.
- `CandidateCard`'s Donors/Voting tabs are a simplified re-creation of `DonorTable`/`VotingRecordTable`'s visual pattern (summary text + source-link pills), not a full port — if those Svelte components' layout changes materially, this composite won't reflect it.
